# Optimized Previews v1.0.0

Read-only previews for OBS Studio's main canvas and an additional canvas,
including Aitum Vertical. Previews can replace the native preview slots or use
separate docks, with configurable frame rate limits and automatic switching
when OBS starts or stops streaming or recording.

Requires **OBS Studio 31.1.0 or later**. Choose the plugin architecture that
matches **OBS**, including when running x64 OBS on Windows ARM.

## Downloads

| Platform | Packages | Requirements |
|---|---|---|
| macOS ARM64 + Intel x64 | `obs-optimized-previews-1.0.0-macos-universal.pkg` | macOS 14+, OBS OpenGL renderer |
| Windows x64 | `obs-optimized-previews-1.0.0-windows-x64-installer.exe` or matching ZIP | Direct3D 11, x64 OBS |
| Windows ARM64 | `obs-optimized-previews-1.0.0-windows-arm64-installer.exe` or matching ZIP | Direct3D 11, ARM64 OBS |
| Linux x64 | `obs-optimized-previews-1.0.0-linux-x64.tar.gz` or `obs-optimized-previews_1.0.0_amd64.deb` | Native OBS; Ubuntu 24.04-compatible libraries |
| Linux ARM64 | `obs-optimized-previews-1.0.0-linux-arm64.tar.gz` or `obs-optimized-previews_1.0.0_arm64.deb` | Native OBS; Ubuntu 24.04-compatible libraries |

The macOS PKG is Developer ID-signed and notarized. Windows installers are not
Authenticode-signed. `SHA256SUMS` covers the release packages.

## Manual testing status

- **macOS ARM64 / Apple Silicon:** the PKG has been tested successfully.
- **Windows x64:** confirmed working correctly.
- **macOS Intel x64:** not yet tested on an Intel Mac.
- **Windows ARM64:** not yet tested manually.
- **Linux x64 and ARM64:** not yet tested manually.

Earlier validation included automated macOS rendering checks with OBS 31.1.0
and 33.0.1, Intel execution under Rosetta, and Linux rendering checks in
containers with Mesa llvmpipe. Manual installation and real-world compatibility
verification remains pending for the platforms listed above as untested.

## Installation

Close OBS before installing or upgrading.

- **macOS:** open the universal PKG. It installs for the current user.
- **Windows:** run the EXE matching your OBS architecture. Use the ZIP for
  portable installations.
- **Linux:** extract the TAR.GZ into your OBS user plugin directory, or install
  the matching DEB with `sudo apt install ./<package>.deb`. These are native
  packages; OBS Flatpak requires a separate extension.

See the [README](https://github.com/Neotecos/obs-optimized-previews/blob/v1.0.0/README.md)
for full installation, configuration, build instructions, and limitations.

## Rendering notes

macOS uses IOSurface and Core Animation. Windows and Linux use asynchronous
GPU readback and Qt presentation, with a 1920×1080 readback bounding box.
macOS performance measurements apply specifically to its IOSurface path.
All previews are read-only. Metal on macOS is unsupported.
